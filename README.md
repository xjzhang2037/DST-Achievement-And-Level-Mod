## Why another achievement mod?
The main goal of why I finally decided to take on supporting this mod was because no one aside from [Chasni's
mod](https://steamcommunity.com/sharedfiles/filedetails/?id=2937640068)
captured the new contents. However, it often has conflicts with a large set of other mods, and doesn't quite work with the main server I play on.

## Guidelines, Goals and Principles
That being said, these are the guidelines in which I will try to stick to when working on this mod. I'm open to reviewing pull requests as well as long as they stay within these guidelines.

1. All achievements are possible with any single character. -- This means that you do not need to own any specific charter or switch in midrun to graduate.
2. This achievement mod should be standalone.
   * This means we will minimize the need to overwrite existing game files.
   * We will use event listeners where applicable.
3. Achievements should encourage players to explore all contents of the game.
   * This means updating it to include new updates from Klei where applicable.
4. Achievements should not be time gated.*

## Roadmap
1. Cleanup of the mod. If I intend to support it for a longer period of time, and update it with new perks, I'll require it to be in a more maintainable state. It would also be easier for other folks to help contribute.
2. The next point is to add/remove some of the new content bosses and updating some of the time sink achievements.
3. After that, I'd be open to suggestions to the mod.

## Notes:
* I personally find the achievements like "walk for xxxx minutes" artificial and shallow as it forces the player to waste time.
  Achievements are something the player should want to do as a challenged and should not be subjected to a mind-numbing grind.
  If it was something like, walk a distance of 10000. That is acceptable, since the player isn't punished by taking perks into movement speed.
